## 📖 Il Progetto
 
Visit San Cataldo nasce a gennaio 2025 come progetto pedagogico e di ricostruzione identitaria della città, gestito da un team di 10 collaboratori.
 
**Obiettivi:**
- Promuovere il turismo valorizzando attrazioni conosciute e sconosciute
- Far riscoprire ai sancataldesi la propria città e le sue tradizioni
 
## ✨ Funzionalità
 
**Homepage** con hero banner e cards per esplorare:
- 📍 Luoghi da visitare
- 🍝 Specialità culinarie
- 🎉 Eventi e feste
- 📜 Storia e Tradizioni
- 🏺 Siti Archeologici
- 🗺️ Itinerari personalizzati
 
**Itinerari Intelligenti** *(in sviluppo)*  
Sistema che propone percorsi su misura in base a: stato d'animo, stagione, tempo disponibile, numero partecipanti e preferenze culinarie.

## 🛠️ Tech Stack

- **Frontend**: React, Bootstrap, React Router
- **Backend**: Express.js, MySQL
- **Database**: Tabelle per luoghi, eventi, storia, itinerari, cibo

## 🚀 Installazione

### Prerequisiti
- Node.js >= 14.x
- MySQL >= 8.0

### Setup
```bash
# Clone repository
git clone https://github.com/lucariggi92/react-VisitSanCataldo.git
cd react-VisitSanCataldo

# Frontend
npm install
npm start

# Backend
cd server
npm install
cp .env.example .env  # configura credenziali MySQL
npm run dev

# Database
mysql -u your_user -p your_database < database/schema.sql
```
